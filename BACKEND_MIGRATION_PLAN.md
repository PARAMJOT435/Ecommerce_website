## Phase 5: Authentication Flow

### 5.1 JWT Strategy

1. **On Login:**
   - User sends email + password
   - Backend verifies credentials
   - Backend returns JWT token (+ refresh token?)
   - Frontend stores token in httpOnly cookie (secure)

2. **On Requests:**
   - Frontend includes JWT in Authorization header
   - Backend middleware verifies JWT
   - Request proceeds if valid

3. **On Logout:**
   - Frontend clears JWT cookie
   - Optional: Blacklist token on backend

### 5.2 Password Reset Flow

1. User enters email
2. Backend generates reset token (short-lived JWT)
3. Backend sends email with reset link
4. User clicks link, enters new password
5. Backend verifies token, updates password
